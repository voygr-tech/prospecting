# VOYGR Prospecting (Codex / AGENTS.md)

This repo ships one skill: [`skills/prospecting/SKILL.md`](skills/prospecting/SKILL.md).
Follow it verbatim for any request to find US local businesses, build a lead
list, or enrich places with owners, contacts, legal entity, status or custom
attributes.

The plugin connects the Prospecting MCP tools at
`https://api.voygr.tech/places/mcp`. Use those tools after browser sign-in when
available. Otherwise use `VOYGR_API_KEY` (or `PLACECALL_API_KEY`, the same
account key) with the skill's API-key workflow. Get the user's OK before any
paid step. Quote the maximum cost when the connected tool provides one.
